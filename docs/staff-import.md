# Import staff

Sign in as an owner or store manager and open **Settings → Staff & Access**.

1. Select **Download Template** and replace both example rows with your staff.
2. Fill in Name, Email, Access Level and Password. Phone is optional. Each email must be unique; it is the user's login. Passwords must contain 8–128 characters.
3. Leave **Cashier-only import** checked for a cashier roster. Use `Cashier` or leave Access Level blank. Other roles are rejected in this mode, including by the server.
4. Save as CSV or Excel (.xlsx), then select **Import Users** and choose the file.

The page reports created and rejected rows and refreshes the staff list. Valid rows are imported even if other rows are invalid. Existing accounts are skipped without changing their passwords or access. If an import stops, refresh the list and retry the file; accounts already created are retained.

Cashiers sign in with the email and password from the file and receive existing cashier permissions. They cannot open staff administration. Give each person their own credentials directly and keep the filled spreadsheet private.

For a mixed roster, an administrator can uncheck Cashier-only import. Supported access labels are Cashier, Bar Staff, Store Keeper, Supervisor, Store Manager and Owner. Only an owner can create another owner.
